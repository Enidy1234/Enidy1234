# SupplierSys — Figma‑ready design package (initial commit)

This folder contains the initial Figma‑ready design assets, tokens, and handoff documentation for the SupplierSys prototype (Company & Supplier dashboards, RFQ/Quote/PO flows). The package includes SVG icons, design tokens, component specs, lightweight screen SVG placeholders, and import/handoff checklists so a designer can recreate a clickable Figma prototype quickly.

Files included:
- design-tokens.json — color, typography, spacing tokens
- components.md — component specs and CSS/Tailwind mappings
- assets/logo.svg — placeholder logo
- icons/*.svg — icon pack (essential icons)
- screens/*.svg — high‑level screen mockup placeholders (desktop & mobile frames)
- handoff/figma-import-checklist.md — step-by-step import & assembly checklist
- handoff/handoff-notes.md — annotated notes and interaction map

How to use:
1. Create a new Figma file and import the SVGs in /assets and /icons.
2. Copy the color & text tokens from design-tokens.json into Figma styles.
3. Rebuild components in the Components page using components.md as spec and then assemble screens using the screen SVGs as visual references.
